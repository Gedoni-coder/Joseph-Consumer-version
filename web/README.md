# JOSEPH consumer web

React + TypeScript + Vite landing page and interactive product preview. This is an additive frontend under `web/`; the historical root HTML/JavaScript app is preserved. Run this package to see the new design.

## Local development

Use Node 22.12+ (validated with Node 24):

```sh
cd web
npm ci
npm run dev
```

For the production build and local preview:

```sh
npm run build
npm test
npm run preview -- --port 5173
```

Open the printed local URL. Do not expose the development server publicly. No environment variables or database are needed for this preview.

## What works

- Responsive landing page, section links and mobile navigation.
- Three dashboard views: overview, commitments and goals.
- Three predefined purchase scenarios with matching balances and explanations.
- Three scripted sample conversations, expandable FAQs and a native early-access dialog.
- Keyboard focus styling, skip navigation, live announcements and reduced-motion support.
- Self-hosted Manrope font and a generated hero artwork optimized to WebP. No remote images, analytics or font requests.

## Product boundaries

All monetary values are explicit fixtures in `src/demo.ts`. They are not generated by the Financial State Engine and do not constitute financial advice. The page does not connect bank accounts, send WhatsApp messages, accept signup submissions, collect email addresses, or store personal data. The early-access panel states that registration is not open. No launch date, pricing, user counts or testimonials have been invented.

The next product pass should introduce routing and an API boundary after the upstream cookie-auth contract is reconciled. Keep financial calculations in the backend: replace preview fixtures with versioned, timestamped state from the authoritative engine when it exists. Before public launch, complete approved privacy/terms documents, production signup and consent, and replace preview wording with verified availability claims.

## Design and assets

The existing navy `#24248f` anchors the brand, with warm ivory and muted lime/mint accents. Typography pairs locally bundled Manrope with a system serif accent. The original generated artwork remains outside the repository; `public/joseph-orbit.webp` is the optimized deliverable (approximately 120 KB). Its square aspect ratio is reserved in the UI.

## Verification limits

An initial strict TypeScript check and production build passed on 13 October 2026 (Vite 7.3.7; 31 modules). Six DOM interaction tests were added for scenario changes, view selection, conversation selection, navigation, and early-access behavior. Execution was blocked first by sandbox process permissions, then by Windows memory-allocation failures even in a single memory-limited process. These tests have not passed yet. A dialog shim in them does not validate native browser focus trapping.

The final build/test rerun and local preview server could not be completed after Windows exhausted memory and disk space. Real-browser screenshots, responsive visual review, screen-reader review, and browser-specific modal behavior remain required before release; the connected browser tool had no available browsers during this pass. Free local disk space and memory, then run the commands above to complete validation.
